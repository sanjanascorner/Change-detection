Time and Resource Log

Project Title

EO-SAR Binary Change Detection using Dual-Encoder EfficientNet-B4 and UNET Decoder

Objective

The objective of this project was to build a deep learning pipeline for binary change detection using pre-event Electro-Optical RGB images and post-event SAR grayscale images. The model predicts pixel-wise changed and unchanged regions from paired satellite imagery.

Notes

- The model uses a dual-encoder architecture because EO and SAR images have different modalities.
- The SAR encoder is initialized randomly because it accepts single-channel SAR input.
- The target masks are converted from multi-class damage labels into binary change labels.
- No-data EO pixels are excluded from loss and metric calculations.
